# CLAUDE.md

The guide for agents working in this repository is [AGENTS.md](AGENTS.md). Read it before
changing anything: it holds the build and test commands as CI runs them, the coding rules, the
compatibility rule for the applications that pin this repository, and the commit conventions.

Then read [docs/CATALOGUE.md](docs/CATALOGUE.md) (what already exists) before writing a new
piece, [docs/NEW-MODULE.md](docs/NEW-MODULE.md) when adding a module, and
[docs/ROADMAP.md](docs/ROADMAP.md) for work that is open.

This file only points; do not put rules here that are not in AGENTS.md.
